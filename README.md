# WilhelminesNaturalBiomesModificado

Adds new biomes (alderswamp, alpine, bambooforest, bushland, heath, mediterranean, outback, palmbeach, wetsavanna) to your Luanti / Minetest world.

**Additive by default:** the mod's biomes are generated *alongside* the biomes Minetest Game provides, so the default biomes (grassland, desert, jungle, tundra, ocean, etc.) are kept and the world becomes more varied. Nothing is cleared unless you explicitly enable the "clear" options in `settingtypes.txt`.
